# rag-chatbot-platform
Multilingual (EN/FR/PT) Retrieval-Augmented Generation chatbot — Master's Thesis, ISLA Gaia.

A FastAPI service with a pluggable LLM provider (local Ollama / hosted Cerebras), a trilingual RAGAS evaluation harness, and a live results dashboard. Containerized with Docker and deployed as a public demo on Hugging Face Spaces.

**Live demo:** https://yazino-rag-chatbot-platform.hf.space
